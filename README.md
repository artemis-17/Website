# Ethan Z. Olson — research portfolio

Static website for GitHub Pages. Open `index.html` or serve this directory locally with `python -m http.server`.

The homepage uses a self-contained Canvas renderer for an interactive, bounded Hill–Clohessy–Wiltshire relative orbit. Visitors can change radial and cross-track amplitudes, spacecraft phase spacing, and orbital phase, or play the orbit. The chief is assumed to be in a circular 500 km Earth orbit; the visualization uses the linearized, unforced two-body equations and is not a flight design tool. The physics runs directly in the browser from `index.html` without a build step, server, external JavaScript package, or generated imagery. Figures on the research page are cropped from Ethan Z. Olson's 2026 master's thesis and retain figure numbers and captions.

Publication URLs for the AAS/thesis, IFAC, and MECC items still need verified public records. Search the HTML for `TODO:` to replace their labeled placeholders. The IEEE Control Systems Letters item links to its DOI. The thesis PDF is intentionally not hosted here.
